SubcultripFeedBot

User-Agent: SubcultripFeedBot/1.0 (+https://youngjoe-kwon.github.io/subcultrip-feed/bot.html)

日本語

このクローラーは、日本を旅行する韓国人向けの旅行会話アプリ（開発中）のために、イベント日程・期間限定コラボカフェの会期・店舗の営業状況といった公開されている事実情報を確認しています。

  • 対象は公式サイトの公開ページのみ。ログインが必要なページ、SNS、チケット販売サイト、地図・レビューサイトにはアクセスしません。
  • 頻度は原則として週1回（開催が近いイベントは1日1回）、同じホストへの間隔は3秒以上。robots.txt（Crawl-delay を含む）に従います。
  • 保存・公開するのは日付・営業状況などの事実と出典URLのみです。本文・画像・ロゴを再配布することはありません。
  • アクセスを止めたい場合は robots.txt に次を追加してください：
    User-agent: SubcultripFeedBot
    Disallow: /
  • ご連絡・削除のご依頼： https://github.com/YoungJoe-Kwon/subcultrip-feed/issues

English

This crawler checks publicly available facts (event dates, limited-time collaboration cafe periods, store open/closed status) on official websites for a travel-phrase app for Korean visitors to Japan (in development). It never accesses login-only pages, social networks, ticketing sites, or map/review sites; it waits at least 3 seconds between requests to the same host and follows robots.txt including Crawl-delay. Only facts and source URLs are stored and published — no page text, images or logos. To opt out, add User-agent: SubcultripFeedBot / Disallow: / to your robots.txt. Contact or removal requests: GitHub issues.
